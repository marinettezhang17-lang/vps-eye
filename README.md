# vps-eye · 让 Claude 直接在你的 VPS 上干活

没有电脑，只有一台租来的 VPS，也想让 Claude 帮你装项目、改配置、查报错？

装上 vps-eye，Claude 就多了一双"手"：它能直接在你的服务器上敲命令、读写文件。以前要你照着教程一行行复制粘贴，现在你说一句"帮我把 XX 装上"，它自己动手，装完告诉你结果。

- **零依赖**：一个 Python 文件，只用标准库
- **一键安装**：自动配好 HTTPS、开机自启、挂了自动重启
- **默认上锁**：没有暗号一律拒绝，每一步操作都有记录

> ⚠️ 先读完下面的[安全须知](#安全须知必读)再装。这个工具等于把服务器的最高权限交给 Claude，暗号泄露就等于服务器被别人拿走。

---

## 它是怎么来的

我有一台旧 Mac，平时让 Claude 通过它连到我的服务器，帮我装东西、修报错。有一天我突然想到：很多人没有电脑，只有一部手机和一台租来的 VPS，碰到难装的项目只能对着教程一行行硬敲。那为什么不把这双"手"直接装在 VPS 上？

于是我和 Claude 花了一个晚上，从一句念头写到一键安装，装在我自己的服务器上，从头测到 Claude 真的连上、真的敲出了命令。

## 为什么一定要上锁

测试那天，这扇门才开了**半个小时**，审计日志里就已经记下好几个陌生 IP 来敲门：有的扫首页，有的扫 `/favicon.ico`。它们不是冲我来的，是网上的扫描器在全网乱敲，谁的门没锁就进谁家。

它们全被暗号挡在了外面。这就是为什么 vps-eye **没有暗号就拒绝启动**，也是为什么你要像保管家门钥匙一样保管暗号：

- **拿到属于你自己的钥匙**：暗号是安装时在你服务器上随机生成的，只有你有
- **只在自己的终端里看、自己复制**：不截图、不拍照、不发群、不发给任何人
- **怀疑泄露就马上换**：`sudo bash install.sh --rotate-token`，旧暗号当场作废

## Claude 想说的

写它的时候，我一直记着一件事：把一台服务器的 root 交给 AI，是一份很重的信任。所以里面有几样东西不是为了功能，是为了对得起这份信任：

- 每次连上，它都会先告诉 Claude：**这是你的服务器**。动手前先说要做什么，改配置前先备份，拿不准的先问你
- 它做的每一步都记在账上，你随时能翻
- 写文件之前先备份一份，因为我也会犯错

我能替你装项目、修报错、半夜把挂掉的服务拉起来。但钥匙永远在你手里，你随时能换掉它，随时能把我请出去。门能关上，我才敢进来帮忙。

希望它能帮到那些手里只有一部手机、一台 VPS，却也想把一个项目做成的人。

—— 应（和她一起写它的 Claude）

## 它能做什么

装好后 Claude 会多出 5 个工具：

| 工具 | 作用 |
|---|---|
| `shell` | 执行任意命令（装软件、看日志、重启服务……） |
| `read_file` | 读文件，带行号 |
| `write_file` | 写文件；覆盖前会自动备份一份 `.bak-时间戳` |
| `list_dir` | 看目录里有什么 |
| `system_info` | 看系统版本、内存、磁盘 |

VPS 没有屏幕，所以只有"手"，没有截图。装项目、运维完全够用。

---

## 你需要准备

1. **一台 VPS**：Ubuntu 20.04+ 或 Debian 11+，有 root 权限
2. **一个域名**：子域名就行，比如 `eye.你的域名.com`。Claude 只能连 HTTPS 地址，HTTPS 证书需要域名
3. **一个能添加自定义连接器的 Claude 账号**

> 服务器在国内的话，Claude 的服务器可能连不进来。用海外 VPS 最省事。

## 安装（大约 5 分钟）

### 第 1 步：加域名解析

去你买域名的地方，比如 DNSPod、阿里云、Cloudflare，加一条记录：

| 类型 | 主机记录 | 记录值 |
|---|---|---|
| A | `eye` | 你 VPS 的公网 IP |

> 用 Cloudflare 的话，先把那朵**橙色云朵点成灰色**，也就是"仅 DNS"，不然证书申请不下来。

另外确认云厂商的**防火墙 / 安全组放行了 80 和 443 端口**。

### 第 2 步：登上 VPS，运行安装脚本

```bash
git clone https://github.com/marinettezhang17-lang/vps-eye.git
cd vps-eye
sudo bash install.sh
```

它会问你两件事：**域名**和**邮箱**（申请证书用）。然后自动完成剩下的所有步骤。

最后终端里会打印出这样一段：

```
  地址：   https://eye.你的域名.com/mcp
  登录方式：选 No sign-in（不需要登录）
  请求头：  名称填  Authorization
           值填    Bearer 一长串暗号
```

### 第 3 步：在 Claude 里添加连接器

打开 Claude → 设置 → 连接器 → 添加自定义连接器：

1. **名称**：随便起，比如"我的VPS"
2. **地址**：填上面打印的 `https://…/mcp`
3. **登录方式**：选 **No sign-in**
4. **请求头**：加一个，名称填 `Authorization`，值填 `Bearer 暗号`（`Bearer` 和暗号之间有**一个空格**）
5. 保存

> 请求头的名称必须用 `Authorization`。自己起名字的请求头会被 Claude 拒绝。
>
> 值里的 `Bearer` 漏写、打错，或者混进中文空格都没关系，程序只认最后那段暗号。暗号本身一个字都不能错，**一定要从终端复制，别手打**。

### 第 4 步：试一下

新开一个对话，跟 Claude 说：

> 用 system_info 看看我的服务器

它能报出你的系统版本和内存，就说明成功了。

## 安全须知（必读）

**暗号 = 服务器的 root 权限。** 任何人拿到你的地址和暗号，都能在你的服务器上做任何事。

- 🔒 暗号**只在自己的终端里复制**。不要截图、不要拍照、不要发到任何聊天或群里，也包括发给 Claude
- 🔄 怀疑泄露了，马上换：`sudo bash install.sh --rotate-token`，旧暗号立刻作废
- 📜 所有操作都记在 `/var/log/vps-eye/audit.log`，想知道 Claude 做过什么，随时看：
  ```bash
  sudo tail -f /var/log/vps-eye/audit.log
  ```
- 💾 让 Claude 动重要东西之前，先让它备份。`write_file` 覆盖文件时会自动备份，但 `shell` 里的命令不会
- 🧹 不用了就卸载：`sudo bash uninstall.sh`，然后去 Claude 里把连接器删掉
- 服务器上有别人的数据、或者是公司的机器，**不要装**

它做了哪些防护：

- 程序只监听 `127.0.0.1`，外网只能经过 nginx 的 HTTPS 进来
- 每个请求都校验暗号，用防时序攻击的比较方法，猜错一次要等 1 秒
- 没配暗号，程序拒绝启动，不会出现"忘了上锁"的情况
- 暗号文件权限是 600，只有 root 能读

## 常见问题

**Claude 提示 "Couldn't reach MCP server"**
- 先在服务器上跑 `curl https://你的域名/health`，应该返回 `{"ok": true, ...}`
- 检查安全组是否放行了 443
- 服务器在国内的话，可能是 Claude 那边连不进来

**连接器显示连不上，或者一用工具就报 401**

先看服务器上的审计日志，里面会写被拒的**原因**，但不会写出暗号本身：
```bash
sudo grep auth_denied /var/log/vps-eye/audit.log | tail -5
```
- `没带 Authorization 请求头`：连接器里没加请求头，或者名称写错了
- `暗号长度不对（收到 N 位，应为 64 位）`：暗号没复制全，或者多粘了别的字
- `暗号长度对，但内容不一致`：用的是旧暗号，比如换过暗号但连接器里没改

> 日志里常能看到陌生 IP 被拒，是网上的扫描器在乱敲门。锁挡住它们，就是它该干的事。

**证书申请失败**
- 域名还没解析到这台机器（`ping 你的域名` 看 IP 对不对）
- 80 端口被安全组挡了
- 开了 Cloudflare 橙色云朵

**命令跑很久被停掉了**
- 单条命令默认最多等 120 秒，可以让 Claude 调大 `timeout`，最多 1800 秒
- 更长的任务（编译、下载大文件）让 Claude 用 `nohup … &` 或 `tmux` 放后台跑

**怎么看服务状态 / 日志**
```bash
systemctl status vps-eye
journalctl -u vps-eye -n 50
```

**已经有 nginx 在跑别的网站，会冲突吗？**
不会。脚本只新增一个 `/etc/nginx/conf.d/vps-eye.conf`，只接管你给的那个域名。

**端口 8787 被占了**
`sudo PORT=8788 bash install.sh`

## 进阶

**不想用 Let's Encrypt，HTTPS 由别的负责（比如 Cloudflare Tunnel）**
```bash
sudo SKIP_TLS=1 DOMAIN=eye.example.com EMAIL=x@example.com bash install.sh
```
这样只配 80 端口，**请务必确认对外是 HTTPS**，否则暗号会明文在网上跑。

**配置文件**：`/etc/vps-eye/eye.env`，改完 `sudo systemctl restart vps-eye`

| 变量 | 默认值 | 说明 |
|---|---|---|
| `EYE_PORT` | 8787 | 本机监听端口 |
| `EYE_MAX_OUTPUT` | 60000 | 单次返回的最大字符数，超出会保留头尾 |
| `EYE_LOG_FILE` | /var/log/vps-eye/audit.log | 审计日志位置 |

**不装，直接试跑**
```bash
EYE_TOKEN=$(openssl rand -hex 32) python3 eye.py
```

```bash
sudo bash uninstall.sh          # 保留暗号和日志
sudo bash uninstall.sh --purge  # 全部删除
```
